# Environment

## Clang

Clang is a compiler for C programs.

e.g. `clang main.c -o cgit`

## LLDB

LLDB is a debugger. Run the executable through lldb and step through the program to see where errors are occuring.

e.g. `lldb cgit`

## Make

Make is a build tool. you create a Makefile at the project root and define commands to turn source code into programs or run commands like testing.

## libc

libc is the standard library for C

e.g. `#include<stdio.h> ... printf("Hello World");`
